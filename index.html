ISO 27001 Compliance Program for Multi-Cloud Environment

Compliance

A global telecommunications company operating across Azure, AWS, and a third cloud provider needed to ensure 100% compliance with ISO 27001, SOX, DORA, and PCI-DSS controls across their multi-cloud infrastructure.

Key Actions

  • Designed and implemented security posture controls and baselines across three cloud platforms
  • Executed technical risk assessments and CSPM strategies, remediating vulnerabilities in 20%+ of 5,000+ assets
  • Translated complex regulatory requirements into actionable technical security controls and remediation plans
  • Conducted technical audits validating compliance across all regulatory frameworks

Results

  • 100% compliance with ISO 27001, DORA, SOX, and PCI-DSS achieved
  • Security maturity improved from Level 2 to Level 4 (6-level scale)
  • Vulnerabilities remediated across 1,000+ cloud assets

SOX Compliance Hardening: From 65% to 90%

Risk Management

A major enterprise with 3,500+ critical assets was failing SOX compliance at 65%. A systematic hardening and vulnerability analysis program was needed to meet regulatory thresholds.

Key Actions

  • Performed comprehensive hardening and vulnerability analysis using Nessus (Tenable SC)
  • Strengthened access governance through periodic entitlement reviews and privileged access controls
  • Automated key access management controls, achieving 80% maturity level
  • Maintained SOX and ISO 27001 controls, supporting all audit requests

Results

  • SOX compliance increased from 65% to 90%
  • 80% access governance maturity achieved through automation
  • Successful certifications maintained for all strategic clients

Third-Party Risk Management Framework & Vendor Onboarding

TPRM

An educational institution needed a standardized approach for evaluating SaaS vendor security risks during the onboarding process, with no existing TPRM framework in place.

Key Actions

  • Developed a standardized security checklist for SaaS vendor onboarding
  • Conducted end-to-end review of security risk methodology, improving mitigation strategies
  • Designed an institutional Secure Data Deletion Policy aligned with NIST and ISO 27001
  • Supported compliance assurance activities across the institution's security program

Results

  • 100% alignment with Third-Party Risk Management (TPRM) requirements
  • Strengthened data lifecycle governance with NIST/ISO-aligned policy
  • Improved risk decision-making through enhanced methodology

Security Center of Excellence (CoE) & Governance Program

Governance

A global organization needed a structured approach to manage security compliance, coordinate security committees, and align cross-functional teams with compliance requirements.

Key Actions

  • Led the Security CoE as Product Owner, managing backlogs using Agile (Scrum/Kanban)
  • Directed security committees and sub-committees within the CoE
  • Participated in local, regional, and global security committee meetings
  • Defined OKRs and security objectives aligned with business requirements
  • Managed security policies, created, updated, and ensured effective implementation company-wide

Results

  • Organization's security maturity elevated from Level 2 to Level 4
  • Security policies effectively implemented across the whole company
  • Cross-functional alignment achieved through structured committee governance

Security Architecture Review & Production Sign-Off

Architecture Review

As part of the Security CoE, I served as the architecture review gatekeeper for production deployments, ensuring every system design incorporated secure components, proper access controls, and compliance alignment before receiving production sign-off.

Key Actions

  • Reviewed system architectures for secure component selection and configuration (WAF, IAM, encryption, network segmentation)
  • Validated that designs followed Zero Trust principles — no implicit trust, least privilege, defense-in-depth
  • Conducted security control gap analysis against ISO 27001, SOX, and PCI-DSS requirements
  • Provided production sign-off only after all critical and high security findings were remediated
  • Collaborated with engineering teams to translate security requirements into technical implementations

Results

  • Zero critical vulnerabilities in production deployments under my review
  • Security requirements integrated into SDLC from design phase, not bolted on after
  • Architecture review process established as organizational standard within the CoE
